# Clawd 桌宠（Windows）

Clawd 会站在任务栏上面走来走去，盖在所有窗口上面。用 Windows 自带的 PowerShell 运行，不用装任何东西。

## 启动

1. 下载整个文件夹（里面有 `Clawd.bat`、`clawd-pet.ps1`、`ClawdPet.cs`）
2. 双击 **`Clawd.bat`**

第一次启动要编译一下，大约 1～3 秒。

## 怎么玩

- **点它**：摸摸头，开心冒爱心。**连戳 5 下它会生气**，炸毛冒「井」字
- **按住拖动**：拎起来，松手会掉下去。甩一下可以把它扔出去，摔重了会晕
- 它的**眼睛会跟着鼠标转**
- **右键它**打开菜单：
  - 喂饼干、摸摸头、跳一下、睡觉、**打开 Claude**
  - **定在这里**：打开后，拖到哪儿它就待在哪儿，不会掉下去也不乱跑。位置会记住
  - **一起玩** →
    - **跳舞**：所有 Clawd 一起蹦，冒音符
    - **扔个球**：屏幕上掉下一个球，它会追着踢。球可以用鼠标拖着扔
    - **追鼠标**：鼠标在哪它就追到哪
    - **再来一只 Clawd**：最多 7 只，每只颜色不一样，会一起抢饼干
  - **番茄钟**：25 分钟专注，头顶显示倒计时。专注期间它不说闲话，时间到了大家一起跳舞提醒你休息
- **右下角托盘图标**：右键菜单和上面一样，左键点一下可以把它叫回来
- 放着不管它会自己溜达、说话，3 分钟没人理就睡觉
- 饱腹、心情和定住的位置保存在 `%APPDATA%\ClawdPet\state.txt`

## 常见问题

- **双击没反应**：在文件夹空白处按住 Shift 右键 →「在此处打开 PowerShell 窗口」，输入
  `powershell -ExecutionPolicy Bypass -File .\clawd-pet.ps1`
  这样能看到报错信息。
- **杀毒软件拦截**：有些杀毒软件会拦截隐藏窗口运行的 PowerShell，选择「允许」就行。代码全在 `ClawdPet.cs` 里，可以自己看。
- **想关掉开机启动**：右键 Clawd，再点一下「开机自动启动」取消勾选。
